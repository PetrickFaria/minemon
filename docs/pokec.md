# PokéC

PokéC is a two-block terminal that browses all 151 Gen I species in Pokédex order. The client creates previews only for the 18 cards on the current page and uses the existing GeckoLib model, texture, renderer, and idle controller. Preview entities are never inserted into the world and have AI disabled.

## Economy configuration

The server creates `config/minemon/pokec-economy.toml` on first start. Edit it and run `/pokec reload` as an operator to reload the values. The initial rarity defaults are:

| Rarity | Souls | PokéCoins |
|---|---:|---:|
| Common | 8 | 100 |
| Uncommon | 16 | 250 |
| Rare | 32 | 600 |
| Very rare | 64 | 1,500 |
| Legendary / mythical | 128 | 4,000 |

The file contains one `species.<slug>.rarity` line for every species. Add `species.<slug>.coins = N` or `species.<slug>.souls = N` to override a species. Change `rarity.<rarity>.coins` and `rarity.<rarity>.souls` to change category defaults. Change `starters` or `firstPurchaseFree` for the initial unlocked group and one-time free purchase rule. Negative or malformed numeric values retain the safe default. Existing player unlocks, balances, deposits, and free-purchase state remain in player persistent data when the file is reloaded.

Use `/pokec coins <player> <amount>` as an operator to set a test balance. The mod does not add currency drops or gameplay rewards. Soul items are registered for all 15 types that occur in Gen I; souls are not generated by the mod.

## Player actions

Click a locked base species card while holding one matching primary-type soul to deposit one soul. Deposits persist per player and species. Evolution cards remain locked until the immediately preceding owned species evolves into them. Once a species is unlocked, clicking its card purchases a tame Minemon owned by the player. The first completed purchase is free; later purchases use the configured price. The server validates the open terminal, range, species, soul item, price, balance, owner, spawn position, and transaction ID before mutating player data.

The existing Minemon code has no evolution trigger or evolution operation. PokéC provides `MinemonCreature.notifyPokecEvolution(String)` as the server-side integration point: an evolution implementation must call it on the owned source entity after a successful transition. The method validates the owner and the declared one-step evolution edge; it does not create an evolution mechanic or unlock unrelated branches by itself.

## Data source

`data/minemon_gen1/pokec_species.json` lists the National Pokédex number, display name, Gen I type(s), starting rarity, and in-generation evolution parent for every card. The first listed type is the soul type. PokéC reuses the registered species definitions and existing GeckoLib resources.
